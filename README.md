# لغتي التفاعلي

نسخة تفاعلية منفصلة عن تطبيق **لغتي**: كل قصة صارت **كتاب قصص مصوّر**، ورفيق الطفل فيه البومة **بوبو** 🦉.

## تحميل التطبيق (أندرويد، بدون نت)

https://github.com/mhoaltanany-max/lughati-game/releases/latest/download/lughati-book.apk

## كيف بيشتغل

- **المكتبة:** رفّ لكل مستوى (رفّ الصغار، المغامرين، الأبطال، وقصص العائلات)، وكل قصة كتاب بغلاف ملوّن.
- **الكتاب:** كل جملة صفحة فيها صورة (مشهد بسماء وأرض وصور الكلمات). الصفحة بتنقرأ بالصوت الأصلي وكل كلمة بتضوي لحظة ما تنقال، وفي قراءة تلقائية بتقلب الصفحات لحالها.
- **اضغط على أي كلمة** بتسمعها وبتشوف معناها، و**اضغط على أي صورة** بتنط وبتحكي اسمها.
- **أسئلة بوبو:** كل كم صفحة بوبو بيطلع بسؤال عن اللي سمعته: اسمع وين الصورة، شو الكلمة اللي سمعتها، شو معناها، رتّب الجملة، كمّل الجملة.
- **آخر الكتاب:** نجوم، ملصق جديد للألبوم، وكروت كلمات القصة.
- **كلماتي:** كل الكلمات اللي مرّت بالقصص، ككروت بتنقلب وبتحكي، ولعبة سريعة فيها.

## الملفات

| الملف | المحتوى |
|---|---|
| `www/index.html` · `www/book.js` | التطبيق |
| `www/emo.js` | صورة لكل كلمة ملموسة |
| `www/content.js` | القصص والترجمات وتوقيت الكلمات |
| `www/audio/` · `www/wp/` | تسجيلات القصص وأصوات الكلمات |

كل تعديل على الفرع `main` بيبني نسخة جديدة تلقائيًا على نفس رابط التحميل.
