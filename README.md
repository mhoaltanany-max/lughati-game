# لغتي اللعبة

نسخة لعبة منفصلة عن تطبيق **لغتي**: نفس القصص وتسجيلاتها وأصوات الكلمات، بس على شكل رحلة يومية بألعاب، مع رفيق اسمه **بوبو** 🦉.

## تحميل التطبيق (أندرويد، بدون نت)

https://github.com/mhoaltanany-max/lughati-game/releases/latest/download/lughati-game.apk

## العوالم

- 🧸 **عالم الصغار** (المستوى الأول، ٣٦ قصة): طفولي كتير. صور لكل كلمة، بالونات، وحش جوعان بتطعميه الكلمات، ملصقات بتنجمع بألبوم، وبوبو بيشجّع.
- 🏝️ **جزيرة المغامرين** (المستوى الثاني، ٤٣ قصة) و🏔️ **قمّة الأبطال** (المستوى الثالث، ٨ قصص).
- 👨‍👩‍👧 **عائلات الكلمات** (١١١ قصة حسب الموضوع).

## كيف بيمشي اليوم

1. **مراجعة** كلمات الأيام السابقة اللي إجا وقتها.
2. **محطات قصة اليوم**: كل محطة ٨–٩ كلمات: تعرّف، توصيل، ألعاب.
3. **وقت القصة**: تسمع القصة كاملة مع تظليل كل كلمة، وبعدين التحدي.

وكمان: صالة ألعاب (البالونات، طعمي الوحش، اسمع والقط الصورة، الذاكرة، مطر الكلمات، سباق الدقيقة، ركّب الكلمة، تحدي السمع)، صندوق مراجعة، نقاط ونجوم وشخصيات.

## الملفات

| الملف | المحتوى |
|---|---|
| `www/index.html` · `www/game.js` | اللعبة |
| `www/emo.js` | صورة (إيموجي) لكل كلمة ملموسة |
| `www/content.js` | القصص والترجمات وتوقيت الكلمات |
| `www/audio/` · `www/wp/` | تسجيلات القصص وأصوات الكلمات |

كل تعديل على الفرع `main` بيبني نسخة جديدة من التطبيق تلقائيًا، وبتطلع على نفس رابط التحميل.
